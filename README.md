# 🧮 Web Calculator

A clean, responsive browser calculator built using vanilla JavaScript, HTML5, and CSS Grid. 

## 🚀 Features
- **Basic & Chained Math:** Performs addition, subtraction, multiplication, and division seamlessly in sequence.
- **Input Protection:** Prevents multiple decimal entries per number.
- **Error Safeguards:** Safely handles division by zero without crashing.
- **Clear & Backspace:** Easy reset options for fixing typos or starting fresh.
- **Modern UI:** Built using a 4-column CSS Grid layout for a clean display.

## 🛠️ Built With
- **HTML5** - Page structure and elements
- **CSS3 / CSS Grid** - Responsive layout and custom styling
- **JavaScript (ES6)** - State management and calculation logic
